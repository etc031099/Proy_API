## Diseño de interfaz

- Se mantienen las ocho pestañas existentes. Resumen incorpora cuatro accesos a Predicción, Clientes, Ventas y Productos relacionados.
- Cada técnica muestra primero nombre, tipo, objetivo y evidencia breve. “Ver metodología y limitaciones” abre un bloque nativo accesible por teclado y toque; los iconos de ayuda muestran definiciones cortas por hover, foco o toque y se cierran con Escape.
- Los contratos existentes suministran métricas, fechas, versiones, estados, tamaños de muestra y limitaciones. No se copian valores de evaluación a la presentación como constantes.
- Predicción mantiene separadas la evaluación supervisada HGB y la media móvil MA28 estadística operativa; HGB V3 de 28 días sigue indicado como no aprobado para operación. WAPE se explica como error relativo, nunca como accuracy. La curva Real vs. Predicho continúa no disponible porque no hay serie TEST persistida.
- Clientes conserva separado RFM por reglas y K-Means. Distribución, perfiles, PCA y tabla siguen visibles. PCA se presenta únicamente como proyección visual.
- Ventas conserva serie histórica, marcas ×, tooltip y tabla. Las señales se describen como comportamientos atípicos para revisión contextual, nunca como fraude, error o incidente confirmado.
- Productos relacionados conserva las reglas A → B, nombres antes que SKU y soporte, confianza, lift y tickets. Una asociación positiva no se presenta como causal.
- Inventario se explica como pronóstico combinado con reglas operativas. Proveedores se identifica como analítica descriptiva y no recibe un badge ML.
- Salud humaniza nombres conocidos como `grossMarginCents`, `CUSTOMER_AT_RISK_COUNT`, `criticalInventoryExposure` y `MOVING_AVERAGE_28`. No se calcula ni muestra score global.

## Explicaciones y limitaciones

Los bloques expandibles explican objetivo, funcionamiento, variables, evaluación, versión/corte y limitaciones. HGB explica árboles secuenciales; K-Means explica centroides, RFM, Silhouette y ARI; Isolation Forest explica aislamiento, score, contamination y ausencia de ground truth; FP-Growth explica coocurrencia y support/confidence/lift. Las limitaciones se mantienen visibles al abrir metodología: muestra exploratoria de clientes, datos sintéticos, ausencia de etiquetas reales para anomalías y cutoff histórico fijo para Market Basket.

La tasa observada de señales de Isolation Forest no es fraude ni tasa de error. Score más bajo indica mayor atipicidad y no es probabilidad. MA28 es un método estadístico. Inventario y proveedores no se describen como aprendizaje automático.

## Accesibilidad y adaptación

Los gráficos conservan títulos, unidades/tooltips, alternativas textuales o tablas y marcas que no dependen solo del color. Las rejillas usan breakpoints y las tablas mantienen desplazamiento horizontal en pantallas estrechas.

### Proveedores: causa y corrección

La causa identificada en el código es una reinterpretación de estado entre pestañas: `ExtendedAnalyticsPanel` conservaba `data` de Clientes durante el primer render de Proveedores. Ambos contratos tienen `items`, por lo que el cast dejaba pasar los datos anteriores a `SuppliersView`; este leía `summary.averageLeadTime.days`, inexistente en Clientes. El efecto que limpiaba el estado se ejecutaba después del render fallido. Esto explica la dependencia de la ruta de navegación sin atribuir el crash a Render. La regresión local reproduce esa transición con la nueva solicitud pendiente. No se inspeccionó un stack cloud en esta fase, por lo que no se afirma haber descartado otras excepciones de producción.

- El contenido se remonta por pestaña. La respuesta principal se vincula a pestaña/período/reintento; no se presenta un resultado de otro contexto durante la transición.
- La guarda de contrato de proveedores exige la estructura principal y la colección `items`. Métricas opcionales ausentes se muestran como “No disponible”; se conserva el cero observado y no se convierte `null` en cero. Productos opcionales del detalle se tratan como colección sin elementos presentables cuando no están disponibles.
- Los detalles tienen un identificador de solicitud, contexto y guarda de montaje. Una respuesta anterior no sustituye a la selección nueva ni actualiza un panel abandonado. Las solicitudes principales conservan la invalidación del patrón existente de efectos.
- Gráficos y tooltips filtran métricas no finitas y toleran valores ausentes. Durante la carga aparece un estado explícito; no se dibujan gráficos sin datos válidos.
- `AnalyticsErrorBoundary` protege cada pestaña y los paneles extendidos/evaluación. El fallback de proveedores dice “No se pudo mostrar la analítica de proveedores.” y permite reintentar sin mostrar la excepción. La navegación queda fuera del boundary. El reintento del panel extendido remonta su loader.
- Se mantiene retry manual. No hay reintentos automáticos para 502/503/504, red/timeout ni para 401/403/404/422.
