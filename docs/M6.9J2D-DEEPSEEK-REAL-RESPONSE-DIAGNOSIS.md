[DeepSeek Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/).

truncation and is not accepted as complete. Documented consumption uses prompt_tokens,
completion_tokens and total_tokens. Cache accounting uses prompt_cache_hit_tokens and
prompt_cache_miss_tokens; cached_tokens is also available in prompt_tokens_details.

Normalization:

| Provider field | Internal field |
| --- | --- |
| prompt_tokens | inputTokens |
| completion_tokens | outputTokens |
| total_tokens | totalTokens |
| prompt_cache_hit_tokens / prompt_tokens_details.cached_tokens | cachedInputTokens |
| prompt_cache_miss_tokens | cacheMissInputTokens |
| completion_tokens_details.reasoning_tokens, if supplied | reasoningTokens |

values stay null. Malformed supplied counts, inconsistent totals or contradictory
cache breakdown are INVALID rather than ABSENT. Complete core counts with missing
cache breakdown keep token totals but cannot produce the configured cache-aware cost
range. No token estimate from string length replaces usage.

cache hit/miss counts produce its configured min/max cost range. estimatedCostUsd
