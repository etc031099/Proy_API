# M6.9F.6A.2 — Dashboard visual de Inteligencia del Negocio V3

## Alcance y navegación

La ruta existente `/demand-forecast` se conserva para bookmarks, pero ahora muestra «Analítica e Inteligencia del Negocio». El enlace del menú dice «Inteligencia del Negocio». La página contiene solo tres secciones: Resumen, Predicción e Inventario. Las pestañas usan controles nativos con roles/tab labels accesibles; no se muestran secciones futuras vacías.

## Integración API

El navegador utiliza `apiClient` autenticado del backend y nunca llama directamente a FastAPI/ML:

- `GET /api/intelligence/summary`
- `GET /api/intelligence/inventory?limit=20`
- `GET /api/intelligence/products/:sku/forecast?horizonDays=1|7|14`
- `GET /api/intelligence/products/:sku/inventory`
- `GET /api/products?search=...&page=1&limit=20` para búsqueda acotada del selector.

Los contratos TypeScript están en `frontend/src/types/businessIntelligence.ts`. Los tipos mantienen estados y valores nulos explícitos; presentación no calcula márgenes, riesgo, forecast, ROP, seguridad, clasificación ni cantidad recomendada.

## Contenido y estados

Resumen muestra ventas, unidades, tickets, ticket promedio, margen bruto, riesgo, reposición y compras pendientes. Cero ventas se presenta como cero válido. Margen `UNAVAILABLE` no se convierte a cero; `PARTIAL` se etiqueta y explica. El modo LIVE/Historical y la fecha disponible se muestran discretamente, sin hashes ni versiones internas.

El selector no elige un SKU arbitrario. Busca por nombre o SKU con debounce de 300 ms y muestra presentación y SKU. El ranking de inventario conserva el orden del API. Elegir un producto desde la tabla selecciona ese SKU y abre su vista de pronóstico; no hay acciones de escritura.

Forecast ofrece únicamente 1, 7 y 14 días, el método aprobado y su cutoff. El gráfico presenta la serie observada: `ZERO` es cero, `MISSING` deja un hueco y `PARTIAL` usa una serie visual separada. El contrato entrega totales por horizonte, no predicción diaria; por ello la previsión se muestra como total de rango y no se dibuja como curva diaria fabricada. Cold start/historial insuficiente no muestra una previsión.

Inventario muestra stock, entrante, posición, demanda, cobertura, stock de seguridad, punto de reorden, cantidad recomendada, riesgo y ABC/XYZ cuando están disponibles. Los valores nulos se representan como «No disponible». Riesgo incluye texto además de color; reposición inmediata se limita al booleano devuelto por el motor.

## Responsive y accesibilidad

Las tarjetas se reorganizan por breakpoints; el ranking mantiene una región de scroll horizontal en pantallas estrechas. Selector y ranking son operables con teclado. Hay etiquetas asociadas, roles de tabs/panel, estados de carga/anuncio, errores con retry, captions de tabla, descripciones de gráficos, badges textuales y estados de riesgo no dependientes únicamente del color.

## Pruebas

La suite focal `frontend/test/businessIntelligenceDashboard.test.tsx` valida el nombre de navegación, título, KPIs/cero, margen unavailable/partial, búsqueda y no selección arbitraria, horizontes aprobados, estados de observación, cold start, detalle/recomendación de inventario, risk label, ranking y error seguro. Se ejecuta con Vitest usando `frontend/vitest.config.ts`.
