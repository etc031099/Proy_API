### Hallazgo de paridad UTF-8 en Windows (13-oct-2026)

La primera ejecución autenticada llegó a las siete rutas cloud. La comprobación se detuvo en `business` porque Windows decodificó la salida JSON UTF-8 de Node con la página ANSI local: por ejemplo, el nombre canónico `Pan Francés fresco paquete 4 unidades` aparecía localmente como `Pan FrancÃ©s fresco paquete 4 unidades`. Cloud devolvió el nombre canónico correcto; el dataset/hash de cloud no fue la causa. Se fijó `encoding="utf-8"` en las llamadas Python→Node que consumen texto y se agregó una regresión del nombre PAN-FRE-001. El motor de forecast congelado permanece intacto. El hash de siete dominios con nombres UTF-8 canónicos es ahora `5a4f77ca41e469b005f3a6b7404c205ab6796b5688e0e2007018c4f67b3d78e9`; el hash de las siete solicitudes nominadas locales es `07d3f891303a8e24ae0ca419c1fc8b5bcb3e11e7bd87645034990a892bcdd309`.
