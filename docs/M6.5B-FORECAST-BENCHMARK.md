## Incidente de TEST y decisión

El marker registra `TEST_EXECUTION_STARTED_DO_NOT_RERUN` a `2026-10-13T05:55:23Z`, con `fitCountBeforeTest=68`, dataset/config hashes y estrategias congeladas. La pasada completó los cálculos de TEST en memoria y terminó al llegar a la fase de smoke batch80, con `NameError: predict_forecast_batch is not defined`, porque faltaba importar esa función en el runner. El proceso terminó antes de guardar `benchmark-results.json` o un resumen de test; los resultados calculados dentro del proceso ya no están disponibles.

La dependencia faltante se importó y se agregó una prueba de integración de símbolo para evitar esa regresión. **No se reejecutó TEST**, ni se reconstruyeron sus métricas: la única ejecución permitida quedó consumida y un cálculo posterior sería una segunda mirada al holdout. Tampoco se creó ningún `.joblib` V3. El marker ignorado se conserva deliberadamente como evidencia y guard para impedir que este workspace repita el test.

Por tanto no hay cifras publicables de test 1d/7d/14d/28d, gates TEST, comparación final, artefacto, reproducibilidad del bundle, rendimiento batch80 ni RSS/CPU finales. La selección baseline de validation no basta para afirmar «estrategia baseline aprobada» sin los gates del test sellado. Tampoco se puede concluir que “ningún modelo pasa test”. El estado es **bloqueado por pérdida del reporte tras consumir TEST**.
