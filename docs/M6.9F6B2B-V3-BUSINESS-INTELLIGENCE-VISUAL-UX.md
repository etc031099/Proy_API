## Diseño y visualizaciones

- Resumen: jerarquía comercial e inventario, KPIs existentes, distribución de riesgo y clasificaciones ABC/XYZ presentadas con barras compactas. No se duplica el ranking ni se deriva una matriz ABC-XYZ que la API no entrega.
- Predicción: conserva horizontes 1/7/14. Explica que la media móvil usa hasta 28 días cerrados; el gráfico etiqueta ejes, fechas, unidades y estado diario. El total del horizonte no se distribuye en días futuros.
- Inventario: mantiene KPIs y clasificación del motor; añade explicación textual derivada solo de riesgo, cobertura, bandera de reposición y cantidad recibidos. Incluye ayuda para cobertura, stock de seguridad, punto de reorden, ABC y XYZ.
- Ventas: conserva Hoy/7/30 días, cero y margen no disponible; añade líneas de ingresos/unidades si la serie tiene al menos dos puntos y barras de ranking cuando hay valores disponibles.
- Clientes: barras para segmentos RFM retornados, tabla con recencia/frecuencia/monetario/ticket/última compra y selección de fila para detalle. Consumer Final conserva su exclusión individual.
- Proveedores: KPIs y barras para gasto, pedidos, lead time y puntualidad únicamente cuando el payload trae evidencia numérica; `null` nunca se convierte en cero. La fila permite consultar detalle y productos suministrados.
- Productos relacionados: nombres humanos como contenido principal y SKU secundario. Reglas presentan soporte, confianza, lift y tickets con explicaciones no causales; el análisis se declara histórico hasta el 12/10/2026 y no se recalcula.
- Salud: tarjetas por dominio con estado, frescura, hasta tres métricas e insights disponibles; no crea score global.

## Ayuda, accesibilidad y responsive

`MetricInfo` abre una explicación breve al pasar el cursor o enfocar el control; el botón accesible permite mantenerla abierta con clic/toque. `ChartCard` unifica títulos y descripciones. Las ocho pestañas siguen siendo las mismas y permiten desplazamiento horizontal en pantallas estrechas; las tablas conservan encabezados y scroll horizontal. Gráficos usan Recharts ya instalado, con textos alternativos y tooltips con unidades/fechas. El estado vacío, error, cero observado y valor no disponible se distinguen sin sustituir datos.

## Estados y performance

Se conservan el loading, errores con reintento y limpieza de datos anteriores durante cambios de consulta. Detalles de cliente/proveedor solo cargan tras seleccionar una fila; no se agregan llamadas por render ni nuevas requests. Los gráficos se omiten si no hay datos suficientes.
